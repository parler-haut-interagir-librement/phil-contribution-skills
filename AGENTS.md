# Contributing to `phil/*` and `tilttek/*` packages

Read the skill that matches the work before writing, and apply every rule in it.

| Work | Read |
|---|---|
| PHP, Twig or Stimulus code of a package | [`skills/phil-code-contribution/SKILL.md`](skills/phil-code-contribution/SKILL.md) |
| README, `doc/`, their French mirror, CHANGELOG or docblocks | [`skills/phil-docs-contribution/SKILL.md`](skills/phil-docs-contribution/SKILL.md) |
| A `tilttek/*` package, or choosing between Tilttek and PHIL | [`skills/tilttek-contribution/SKILL.md`](skills/tilttek-contribution/SKILL.md), with the two above |

Before pushing, from the root of the monorepo: `composer gates`, `composer packages`, `composer test:next`,
`composer docs`, `composer docs:translations`.
